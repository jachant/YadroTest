Запуск Автотестов:

`go test -v tests/task1_test.go `

Объяснение решения:

На самом деле эту задачу можно решить несколькими способоми, я решил привести одно из самых простых решений, но также эффективных по памяти и времени

Решение задачи основано на проверке того, можно ли распределить шары между контейнерами таким образом, чтобы выполнить заданные нам условия. Для выполнения их нам было необходимо, чтобы сумма количества шаров каждого цвета точно совпадало с емкостью какого-то контейнера. Потому что, при операции 1 забрать и 1 положить общая сумма шаров в контейнере не должна изменяться.
